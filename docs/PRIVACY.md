# WGate 隐私政策

**生效日期**：2026 年 10 月 25 日
**适用应用**：WGate（HarmonyOS 版，包名 `com.wgate.app`）
**版本**：1.0.0

> 本文件对应发布地址：<https://simon2137.github.io/WGate/privacy.html>（AGC 表单里的"隐私政策 URL"就填这个）。
> 线上页面按华为应用市场的标准隐私声明框架组织，同一页提供简体中文 / 繁體中文 / English 三种语言（`?lang=zh|zh-Hant|en`）。改内容时两个文件一起改，`tools/check_keepalive.py` 第 19 节会检查两份副本。

---

本政策依照华为应用市场的标准隐私声明框架编写，并按 WGate 的实际功能逐条填写。WGate 的开发者（下称"我们"）明白个人信息对你的重要性。这一页要回答的问题很简单：你在使用 WGate 时，我们会不会知道你是谁、你连了哪里。

**一句话结论**：WGate 不设账号、不收集个人信息、不上报任何数据。它只做一件事——把你设备上的流量加密后，送到**你自己填写的那台服务器**。

## 一、我们如何收集和使用个人信息

我们不收集、不存储、不上传你的个人信息。

- 没有账号体系：不需要手机号、邮箱、姓名或任何身份信息，也没有注册与登录入口。
- 没有统计与埋点：不采集使用行为、设备标识符、崩溃日志或安装来源。
- 没有广告：不接入广告 SDK，不做定向投放，不推送营销信息。

### 1.1 注册与登录

不适用。WGate 没有账号，也不提供登录，因此不存在与账号关联的个人信息。

### 1.2 个性化推荐

不适用。本应用不含内容推荐功能，不会基于任何信息向你推荐内容或服务。

### 1.3 广告与营销推广

不适用。本应用不展示广告，不发送营销推送，也不向第三方提供任何用于营销的信息。

### 1.4 在你设备上产生并保存的内容

为了让你能用起来，WGate 会在**你设备上的应用私有目录**保存下列内容。它们不会离开这台设备，除非你本人主动导出或展示：

| 内容 | 存放位置 | 是否会离开设备 |
| --- | --- | --- |
| 隧道配置（含私钥、对端公钥、地址、AllowedIPs 等） | 应用私有配置存储 | 否。只有你主动执行"导出备份"或"显示二维码"时，才以你可见的形式输出 |
| 应用设置（主题、语言、自动隧道规则、DNS 等） | 应用私有配置存储 | 否 |
| 启动与内核事件日志 | 应用私有文件目录 | 否。你可以随时查看、清空或导出 |
| 连接期间的收发字节数、握手时间 | 仅内存中统计 | 否 |

## 二、设备权限调用

应用只申请完成功能所必需的 6 项权限，均为普通级别，且只在你使用对应功能时触发：

| 权限 | 用途 | 触发时机 | 拒绝的后果 |
| --- | --- | --- | --- |
| `ohos.permission.INTERNET` | 建立加密隧道，与你配置的服务器通信 | 隧道连接期间 | 隧道无法工作，核心功能不可用 |
| `ohos.permission.GET_NETWORK_INFO` | 识别当前网络类型（Wi-Fi / 移动数据 / 以太网），用于自动隧道与断线重连 | 网络状态变化时 | 自动隧道与重连失效，手动连接仍可用 |
| `ohos.permission.GET_WIFI_INFO` | 读取当前 Wi-Fi 名称，用于"连上某个 Wi-Fi 就启动某条隧道"的规则 | 网络切换时 | Wi-Fi 规则失效，其余功能正常 |
| `ohos.permission.KEEP_BACKGROUND_RUNNING` | 切到后台后保持隧道连接，并在通知栏显示当前隧道与流量 | 应用在后台时 | 切后台可能被系统断开 |
| `ohos.permission.CAMERA` | 扫描 WireGuard 配置二维码 | 仅当你点击"扫描二维码"时 | 可改用"粘贴"导入配置 |
| `ohos.permission.PRIVACY_WINDOW` | 展示私钥或二维码时阻止系统截屏与录屏 | 该页面显示期间 | 可正常使用，仅少了这层防护 |

你可以随时在"系统设置 → 应用 → WGate → 权限"中撤回，也可以在应用内关闭通知、自动隧道等开关；撤回即时生效，不影响其他功能。摄像头画面只在扫描界面内实时解析，不保存、不上传。

## 三、对未成年人的保护

本应用不面向未成年人单独提供服务，也不收集年龄或身份信息。未成年人应在监护人指导下使用本应用。监护人如发现未成年人未经同意使用，可随时卸载——卸载会一并删除本机上的全部配置、设置与日志。

## 四、与第三方共享、转让、公开披露

我们不出售、不出租、不以任何形式向第三方提供你的信息，因为我们手上没有这些信息。

- **不共享**：应用不运营自有服务器，不设中转节点，不存在把数据交给第三方的环节。
- **不转让**：若发生合并、收购或破产清算，本应用不持有可转让的个人信息。
- **不公开披露**：除法律法规强制要求外，我们不会披露任何内容；由于不保有数据，也无从披露。

你的隧道流量直接发往你在配置里填写的那台服务器。那台服务器由你本人搭建和掌控，其日志与隐私实践由该服务器的运营者决定，不属于本政策范围。

## 五、第三方 SDK 与服务商

本应用**未集成任何第三方 SDK**：没有广告、统计、崩溃上报、推送、社交或支付 SDK。

为实现协议与界面，应用内打包了下列开源组件。它们随应用一起运行，不联网、不采集信息、不向任何服务器回传数据：

| 组件 | 用途 | 许可 | 是否收集信息 |
| --- | --- | --- | --- |
| WireGuard 协议与隧道内核（本项目自行编译） | 加密与传输 | GPL-2.0 | 否 |
| Monocypher | X25519 密钥交换、ChaCha20-Poly1305 | CC0-1.0 / BSD-2-Clause | 否 |
| BLAKE2s 参考实现 | 哈希 | CC0-1.0 | 否 |
| Inter 字体 | 界面文字 | SIL OFL 1.1 | 否 |
| Material Symbols | 界面图标 | Apache-2.0 | 否 |
| HarmonyOS SDK / ArkUI | 系统能力 | 华为 SDK 许可 | 系统能力，行为由系统决定 |

## 六、管理你的个人信息

### 6.1 查阅与更正

本机保存的内容都在应用内可见、可改：隧道配置在隧道详情页，设置在"设置"，日志在"设置 → 本地日志"。

### 6.2 删除

你可以删除单条隧道、清空"本地日志"，或在系统里卸载应用。卸载会一并删除全部配置、设置与日志，不在任何地方保留副本。

### 6.3 注销账号

不适用。本应用没有账号体系，无需注销。

### 6.4 撤回同意

在系统设置中关闭单项权限，或在应用内关闭通知、状态通知、自动隧道等开关；撤回即时生效。

### 6.5 个性化推荐开关

不适用。本应用没有推荐功能，也没有相应开关。

### 6.6 停止运营

若本项目停止维护，我们会在项目主页提前公告，并在公告期内保留源码与导出方式，确保你能把配置带走。本应用不含任何云端数据，停止运营不会有数据损失。

## 七、我们如何保护你的个人信息

### 7.1 保存地点与期限

全部内容只保存在你设备上的应用私有目录，不存放在我们的任何服务器上，不涉及跨境传输。保存期限由你决定：直到你删除或卸载应用。

### 7.2 安全措施

- 私钥只在本机生成与使用，不离开设备；
- 展示私钥或二维码时申请 `PRIVACY_WINDOW`，阻止系统截屏与录屏；
- 备份导出与二维码展示都由你主动发起，应用不会自动外发；
- 不设后门、不设遥测；源码以 GPL-3.0 公开，可自行审计；
- 传输使用 Noise_IKpsk2_25519_ChaChaPoly_BLAKE2s，并兼容 AmneziaWG 的混淆参数。

需要说明：没有任何系统能保证绝对安全。若设备已被控制、系统本身被攻破，应用层面的措施无法覆盖这些情形。
