# WGate 隐私政策

**生效日期**：2026 年 10 月 21 日
**适用应用**：WGate（HarmonyOS 版，包名 `com.wgate.app`）

> 本文件对应发布地址：<https://simon2137.github.io/WGate/privacy.html>（AGC 表单里的"隐私政策 URL"就填这个）。正文与代码实际行为一致；改内容时两个文件一起改。

---

## 一、我们收集哪些信息

**不收集。** WGate 没有账号体系，不要求你注册或登录，也不会上报使用行为、设备标识、崩溃日志或统计数据。

应用运行过程中产生的以下内容，全部只保存在你自己的设备上：

| 内容 | 存放位置 | 是否会离开设备 |
|---|---|---|
| 隧道配置（含私钥、对端公钥、地址、AllowedIPs 等） | 应用私有配置存储 | 否。只有你主动执行"导出备份"或"显示二维码"时才会以你可见的形式输出 |
| 应用设置（主题、语言、自动隧道规则等） | 应用私有配置存储 | 否 |
| 启动与内核事件日志 | 应用私有文件目录 | 否。你可以随时在"设置 → 本地日志"里查看、清空或导出 |
| 连接期间的收发流量字节数、握手时间 | 仅内存中统计 | 否 |

## 二、应用申请的权限及用途

| 权限 | 用途 | 何时使用 |
|---|---|---|
| `ohos.permission.INTERNET` | 建立加密隧道，与你配置的服务器通信 | 隧道连接期间 |
| `ohos.permission.GET_NETWORK_INFO` | 识别当前网络类型（Wi-Fi / 移动数据 / 以太网），用于自动隧道与断线重连 | 网络状态变化时 |
| `ohos.permission.GET_WIFI_INFO` | 读取当前 Wi-Fi 名称，用于匹配"连上哪个 Wi-Fi 就启动哪条隧道"的规则 | 网络切换时 |
| `ohos.permission.KEEP_BACKGROUND_RUNNING` | 应用切到后台时保持隧道连接，并在通知栏显示当前隧道与流量 | 应用在后台时 |
| `ohos.permission.CAMERA` | 扫描 WireGuard 配置二维码 | 仅在你点击"扫描二维码"时 |
| `ohos.permission.PRIVACY_WINDOW` | 在展示配置二维码或私钥时阻止系统截屏与录屏 | 仅在该页面显示期间 |

除上述权限外，应用不申请任何其它权限。摄像头画面只在扫描界面内实时解析二维码，不保存、不上传。

## 三、数据共享与第三方

- 本应用**不内置任何服务器**，也不提供订阅或中转服务。隧道流量直接发往你在配置文件里填写的服务器地址，那台服务器由你本人搭建和掌控，其隐私实践不适用本政策。
- 本应用**未集成**任何广告、统计、崩溃上报、推送或社交 SDK。依赖仅有系统能力与自行编译的 WireGuard 内核（随应用打包，不联网）。
- 我们不会出售、出租或以任何形式向第三方提供你的数据。

## 四、数据存储与删除

所有数据保存在设备的应用私有目录中，随应用卸载一并删除。应用内也提供：

- "设置 → 本地日志"：清空启动与内核日志；
- 备份与恢复：删除已导入的隧道。

如你曾导出过备份文件，该文件存放在你选择的位置，需由你自行删除。

## 五、未成年人保护

本应用不面向未成年人单独提供服务，也不收集任何年龄或身份信息。若未成年人使用本应用，应在监护人指导下进行。

## 六、政策变更

若应用功能变化导致数据处理方式改变，本政策会同步更新并在应用内与本页公示，重要变更会在应用更新说明中提示。
