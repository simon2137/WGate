# WGate 隐私政策

**适用应用**：WGate（HarmonyOS 版，包名 `com.wgate.app`）

隐私政策不由本仓库撰写，而是由华为应用市场的协议服务依据本应用的信息生成并托管。**每个语言是一份独立协议，编号各不相同**：

| 语言 | 地址 | 协议编号 |
| --- | --- | --- |
| 简体中文 | <https://agreement-drcn.hispace.dbankcloud.cn/index.html?lang=zh&agreementId=2069872513088805568> | `2069872513088805568` |
| 繁體中文 | <https://agreement-drcn.hispace.dbankcloud.cn/index.html?lang=zh-Hant-TW&agreementId=2069887177466076864> | `2069887177466076864` |
| English | <https://agreement-drcn.hispace.dbankcloud.cn/index.html?lang=en&agreementId=2069895149739073216> | `2069895149739073216` |

引用到它的地方有三处，内容以协议页为准：

| 位置 | 形式 |
| --- | --- |
| 应用内 设置 → 支持 → 隐私政策 | 页面内直接嵌入协议（`@kit.ArkWeb`），按界面语言选对应编号 |
| 仓库发布页 <https://simon2137.github.io/WGate/privacy.html> | 按浏览器语言跳到对应语言的协议页（AGC 表单里的「隐私政策 URL」填这个） |
| 本文件 | 指向三个协议页的索引 |

应用侧只做一件事：按语言挑地址并显示。应用本身没有账号、遥测、统计与广告，隧道配置只存在本机的应用私有目录，这些事实也写在 [REVIEW.md](REVIEW.md) 里供审核对照。
