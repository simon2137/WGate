# WGate 1.0.3 新版本特性

1. 修复桌面卡片偶发显示「正在连接」：没有连接时卡片不会再显示「正在连接」，状态与真实的连接情况一致；卡片也不会再自己变成别的尺寸。
2. 修复 2×4 卡片样式：2×4 尺寸下连接按钮不会再跑到右边，与正常使用时一致；点开关就能连接或断开，不必先打开应用。
3. 新增添加隧道时可命名：粘贴配置、导入 .conf / .zip、扫码添加后，会先弹出命名窗口，输入名称点右上角保存即可；留空或直接关闭则按端点地址命名（窗口里有说明）。手动创建仍走隧道编辑页。
4. 调整部分弹窗样式：命名隧道、默认 DNS、隧道配置、粘贴配置、重新排序、移动到分组、分组操作等弹窗统一为「右上角保存图标、高度贴合内容、底部留白一致」，选项文字与行距也一并收紧，操作更集中。
